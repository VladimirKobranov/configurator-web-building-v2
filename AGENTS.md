# Project language

- Use English for all repository content: source code identifiers, comments, UI text, accessibility labels, documentation, tests, and configuration.
- Keep new and edited user-facing copy in English, including tooltips, errors, and menu items.
- When touching existing non-English text, translate it to English.
- Preserve identifiers defined by external assets or APIs (for example, node names inside `.glb` files) when changing them would break integration. Use English names at the application boundary.
